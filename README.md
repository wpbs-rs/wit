# WIT

The [WIT](https://component-model.bytecodealliance.org/design/wit.html)
definitions for wpbs plugins.

## Dependencies

Each package's `deps` directory is generated by
[wkg](https://github.com/bytecodealliance/wasm-pkg-tools) from the definitions
in the top-level [`deps`](deps) directory and is ignored by git.

Generate them on macOS or Linux with [`gen-deps.sh`](gen-deps.sh):

```sh
./gen-deps.sh
```

Or on Windows with [`gen-deps.ps1`](gen-deps.ps1):

```powershell
.\gen-deps.ps1
```

Run it after cloning the repository and again after changing the definitions
in [`deps`](deps).
